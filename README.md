# 品牌视觉延展与印刷交付

把已经确认的品牌视觉延展到邀请函、证件、展架等实际物料，兼顾视觉一致性、尺寸、文字、制作要求和版本管理。

技能名称：`brand-print-delivery` · [查看技能指令](SKILL.md)

## 适合什么时候用

- 已有品牌手册，需要做一套会议或活动物料。
- 同一视觉要适配横版、竖版、证件和展架。
- 设计即将交给制作方，需要检查文件是否真的可用。

## 开始前准备什么

- 品牌手册、LOGO、已确认的设计和不可修改的文案。
- 每件物料的成品尺寸、方向、数量及所需格式。
- 制作方提供的出血、刀模、打孔、安全区和色彩要求。

## 工作方式

1. 确认本次视觉规范，建立交付清单和版本表。
2. 按物料用途延展设计，只修改用户指定部分。
3. 核对尺寸、像素、文字、安全区和供应商规格。
4. 打开检查交付文件，区分预览文件与制作文件。

## 可以得到什么

- 按需求制作的物料设计、预览和实际交付文件。
- 标明尺寸、格式、分辨率与可编辑程度的文件说明。
- 待制作方确认的规格和版本差异。

## 安装与调用

将完整仓库克隆到自己的技能目录，安装文件夹使用技能名称 `brand-print-delivery`：

```sh
git clone https://github.com/AndrewDavidWY/Sill-brand-print-delivery.git ~/.codex/skills/brand-print-delivery
```

如果使用自定义 `CODEX_HOME`，请放到其 `skills/` 下。同名目录已经存在时先比较版本并保留自己的修改，不要直接覆盖。下载 ZIP 时，同样需保留完整文件结构，并把解压后的安装目录命名为技能名称。

在新会话中确认技能可用，再用下面的方式提出任务：

```text
使用 $brand-print-delivery，依据这份品牌手册制作邀请函和工作证。沿用已确认版式，尺寸见附件；先核对制作规格，再交付预览和可编辑文件。
```

## 使用边界

这是设计与交付方法，不附带通用品牌素材或印厂模板。SVG 内嵌图片不等于纯矢量；修改 DPI 或放大像素也不代表增加了真实细节。实际规格以本次制作方要求为准。
