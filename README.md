# VIS手册交付

从已确认的 LOGO 出发，建立完整、可执行的 VIS 视觉识别规范，交付客户品牌手册 PDF 与配套源文件。

工作主线：**LOGO 已确认 → 形成 VIS 手册 → 交付客户品牌手册及源文件**。

显示名称更新为“VIS手册交付”。技术名称继续使用 `brand-print-delivery`，现有安装目录、调用方式和网站链接保持兼容。[查看 Skill 指令](SKILL.md)

## 适用场景

- LOGO 已定稿，需要建立首版 VIS 手册。
- 已有 VIS，需要完善规范、增加实物应用、调整画幅或修订指定内容。
- 需要将最终品牌手册与真实可继续修改的源文件交付客户。

本 Skill 不重新设计已确认的 LOGO。品牌战略、PPT、SI、IP 和雕塑按用户委托加入，不是每次制作 VIS 的必选项。

## 准备资料

- 已确认 LOGO 母版、品牌中英文名称及已有规范；有矢量原件时优先提供。
- 手册用途、已有版本、页面比例及应用清单；已经在对话中确认的要求可以直接沿用。
- 所需交付格式及制作方规格。只有位图、规格未定或缺少指定源格式时，先标明实际条件。

## 三阶段流程

1. **LOGO 已确认**：锁定母版、命名、比例和组合，核对已有资料与本次修改范围。
2. **形成 VIS 手册**：建立基础规范，制作真实物品照片或具有真实质感的应用示意，完成统一排版、修订和 PDF 全页检查。
3. **交付客户**：提供最终 PDF、实际排版源或可重新生成的源文件、LOGO 与使用素材、预览及简明交付说明，核对文件完整性并标明最新版。

## 交付成果

- 品牌手册 PDF：规范和应用完整，目录、页码、书签及版本一致。
- 源文件与素材：保留制作结构、资源路径和 LOGO 母版，说明可编辑范围及必要依赖。
- 交付说明与核验记录：明确阅读或生产用途、当前版本、检查结果及待确认事项。

源文件格式服从实际制作方式和客户要求，不把整页图片冒充可逐元素编辑文件。应用效果图不能冒充实拍或已生产实物；阅读 PDF 也不自动等于可直接送印文件。

## 安装与调用

```sh
git clone https://github.com/AndrewDavidWY/Sill-brand-print-delivery.git ~/.codex/skills/brand-print-delivery
```

使用自定义 `CODEX_HOME` 时放入其 `skills/` 目录。已有同名目录时先比较版本、保留自己的修改；ZIP 安装也应保留完整文件结构，并使用 `brand-print-delivery` 作为安装目录名。

新会话确认技能可用后，可以这样调用：

```text
使用 $brand-print-delivery。LOGO 已确认，请沿用附件母版制作 VIS 手册，按本项目确定的画幅和应用清单排版。检查 PDF 全部页面，交付品牌手册 PDF、实际源文件与使用素材。
```

修订示例：

```text
使用 $brand-print-delivery，在现有 VIS 上增加指定应用并调整为 16:9。保留原版及已确认的单品配色，更新目录和页码，交付新版 PDF 与配套源文件。
```
